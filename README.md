# composite-lint

All-in-one opinionated selection of linters &amp; config.

## Supported Languages / Ecosystems

### Docker

Using `hadolint` and `trivy`.

### GitHub Actions

Using `actionlint`, `yamllint`, and `zizmor`.

### Go

Using `golangci`.

### Python

Using `flake8`.

### Shell

Using `shellcheck`.

### Terraform

Using `terraform` and `tflint`.

### YAML

Using `yamllint`.
